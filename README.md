# VK-ML
Проекты по предмету "Основы машинного обучения"

### Структура проекта

├── clusterization/ $-$ решение задачи кластеризации  
├── log_reg/ $-$ решение задачи бинарной классификации  
├── .gitignore  
├── enviroment.yml  
└── README.md 


### Как запустить:

``` 
conda env create -f environment.yml
conda activate my_env
```

После этого перейдите в любую из дирректорий и запустите ноутбук в названии которого содержитя подстрока "final_pipeline".  

В каждой из дирректорий также лежит свой файл README.md в котором описана вся информация о самой работе.
